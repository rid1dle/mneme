# Mneme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS clipboard manager (Paste replacement) that captures every copy, shows it on a bottom shelf with search, pinboards, themes and Settings, at under 30 MB idle.

**Architecture:** A `Core` layer (pure Swift + SQLite, no AppKit) holds capture classification, the store, search, retention, paste stack and themes, and is unit-tested by a swiftc-built runner. An `App` layer (AppKit shell: `NSPanel`, status item, Carbon hotkey; SwiftUI views inside) watches the pasteboard, pastes, and draws the shelf and Settings. The shelf's SwiftUI tree exists only while it is open.

**Tech Stack:** Swift 5 mode, AppKit, SwiftUI, system `libsqlite3` (FTS5), ImageIO, Vision, CryptoKit, Carbon (hotkey), ServiceManagement. No third-party packages. `swiftc` via `build.sh` (no Xcode, no SwiftPM).

**Spec:** `docs/design.md` (read it before any task).

## Global Constraints

- Repo `~/work/mneme`. Layout mirrors Kenosis (`~/work/kenosis`): `Sources/Core`, `Sources/App`, `Tests`, `scripts`, `Resources`, `build.sh`.
- Target `arm64-apple-macos14.0`, `-swift-version 5`. Liquid Glass only behind `if #available(macOS 26.0, *)`, materials otherwise (copy Kenosis `Sources/App/Shell.swift` glass helpers).
- Bundle id `local.mneme`, `LSUIElement` true, signed `codesign --force --sign - --identifier local.mneme --requirements '=designated => identifier "local.mneme"'`.
- Data at `~/Library/Application Support/Mneme/` (`mneme.sqlite` WAL, `Blobs/`, `Thumbs/`). Every launch option that takes `--store <dir>` uses that dir instead.
- Defaults: shortcut ⇧⌘V; history kept 30 days; per-item cap 50 MB; poll 0.5 s with 0.25 s leeway; search debounce 80 ms; OCR only after 60 s idle and thermal state nominal/fair; thumbnails 400 px; first frame under 100 ms with 10,000 items; idle footprint under 30 MB, never above 54 MB.
- Skipped pasteboard types: `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`. Default excluded apps: `com.1password.1password`, `com.agilebits.onepassword7`, `com.apple.keychainaccess`, `com.apple.Passwords`.
- Never read pasteboard contents unless `NSPasteboard.general.accessBehavior == .alwaysAllow`. Never call `AXIsProcessTrustedWithOptions` with the prompt option outside first-launch setup.
- No network except link previews (switchable). No telemetry.
- Tests: names read as plain-English specs ("should ..."), the Kenosis harness (`test`, `expect`, `expectEqual`, `runAll`). Run `./build.sh test`.
- UI checks run on the user's screen: snapshot mode never orders a window on screen; no `open` for tests; capture only Mneme's own windows; pause if the user is looking (see memory `feedback_test_launches_on_users_screen`).
- No commits unless the user asks. No em dashes in code, comments or UI text.

## Review Focus

1. **A huge copy** (a 200 MB image, a 10 MB log): skipped as too large or stored with a bounded preview; the app never stalls. Pinned by tests in Task 2 and Task 3.
2. **The same thing copied again and again**, or a burst of copies: one item, moved to the front, never duplicated; the last copy is always captured. Pinned in Task 3 and Task 6.
3. **Types listed but no data** (file promises, an app that quit after copying): skipped as empty, no crash. Pinned in Task 2.
4. **Search text with FTS syntax** (`"`, `*`, `-`, `(`, `NEAR`, `AND`): never throws, searches the literal words. Pinned in Task 4.
5. **A broken store file** at launch: moved aside as `mneme.sqlite.broken-<yyyyMMdd-HHmmss>` and a fresh store opens; the app does not crash-loop. Pinned in Task 1.
